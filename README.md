# Kilifi Aspirants Hub

This package contains the updated static website.

## Files
- `index.html` — the website homepage, including the requested candidate entries and orange colour palette.
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing on the site.

## Publish with GitHub Pages
1. Download and extract this ZIP file.
2. Open your GitHub repository.
3. Upload the contents of the extracted `kilifi-aspirants-hub` folder to the repository's publishing branch/root.
4. Ensure the homepage is named exactly `index.html`.
5. Commit the changes.
6. In the repository, open **Settings → Pages** and select the correct branch and `/ (root)` folder if Pages is not already configured.
7. Visit the GitHub Pages URL shown in Settings → Pages.

## Notes
- The site is a static HTML website.
- Candidate records supplied for this update are included in the `ASPIRANTS` list in `index.html`.
- Phone numbers, email addresses, photos, biographies, and personal manifestos were not supplied for the newly added candidates, so those fields remain blank.
- The optional Supabase backend is not configured in this package. The site can display the included candidate records without it.
